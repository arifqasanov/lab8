01 · Əsas anlayışlar

Performans nədir və necə ölçülür?

Performans — kompüterin vahid zamanda yerinə yetirdiyi işin həcmidir. Sistemin sürəti ən zəif halqadan, yəni darboğazdan (bottleneck) asılıdır. Optimallaşdırmadan əvvəl ölçmə aparılır.

0%

CPU yükü

İşlənmə faizi, tezlik (GHz), nüvə sayı.

0%

RAM

Yaddaşın doluluğu və səhifə faylı fəaliyyəti.

0%

Disk

Oxuma/yazma sürəti (MB/s), cavab müddəti (ms).

0°C

Temperatur

65°C-dən yuxarı throttling, yəni sürət itkisi yaradır.

Əsas metriklər: cavab müddəti (latency), ötürmə qabiliyyəti (throughput), FPS, yükləmə vaxtı.

02 · Aparat səviyyəsi

Aparat komponentlərinin təsiri

Ən böyük sıçrayış çox vaxt aparat yeniləməsindən gəlir. Kamera 3D ana lövhə üzərində RAM modullarına və soyuducu ventilyatora uçur.

Prosessor (CPU)

Çox nüvəli və yüksək IPC-li model hesablamanı sürətləndirir.

Təsir85%
  • Nüvə sayı, L3 keş, boost tezliyi

Operativ yaddaş (RAM)

Minimum 16 GB, ikikanallı rejim, XMP profili. DDR4 və ya DDR5.

Təsir78%

SSD yaddaş

HDD-dən SSD-yə keçid yükləməni dəfələrlə azaldır. NVMe 3000+ MB/s verir.

Təsir95%

Soyutma

Toz və qurumuş termopasta temperaturu artırır. Təmizləmə sabit tezlik verir.

Təsir60%

Qayda: əvvəl ən zəif komponent tapılır, sonra yenilənir. 4 GB RAM üzərində prosessor dəyişmək səmərəsizdir.

03 · Əməliyyat sistemi

Sistem parametrlərinin tənzimlənməsi

1

Başlanğıc proqramları. Task Manager → Startup bölməsində lazımsızlar söndürülür.

2

Enerji planı. «High performance» və ya «Balanced» rejim seçilir.

3

Yeniləmələr və sürücülər. OS, GPU və chipset drayverləri səhvləri aradan qaldırır.

4

Vizual effektlər. Animasiya və şəffaflığın azaldılması zəif cihazı sürətləndirir.

5

Virtual yaddaş. Page file SSD-də saxlanılır, ölçüsü sistemə tərk edilir.

Açılış müddəti (nümunə)

Standart quraşdırma0 san
Startup təmizləndikdən sonra0 san
SSD + təmizləmə0 san

Faydalı əmrlər

  • msconfig — konfiqurasiya
  • sfc /scannow — fayl bütövlüyü
  • cleanmgr — disk təmizləmə
  • perfmon — performans monitoru

04 · Yaddaş və disk

Diskin təmizlənməsi və defraqmentasiya

Fayl blokları (canlı simulyasiya)

Parçalanmış vəziyyət...

Narıncı — sistem, sarı — sənəd, yaşıl — media, kəhrəbaya — proqram.

Nələr edilməlidir?

  • HDD: ayda bir defraqmentasiya, oxuma başlığının yolunu qısaldır.
  • SSD: defraqmentasiya edilmir; TRIM aktiv saxlanılır.
  • Müvəqqəti fayllar, keş və zibil qutusu təmizlənir.
  • Diskin 15–20%-i boş saxlanılır.
  • S.M.A.R.T. ilə disk sağlamlığı izlənir.

05 · Proqram təminatı

Proseslər, brauzer və təhlükəsizlik

Proses monitoru (simulyasiya)

ProsesCPUYük

Yüksək yük yaradan proses bağlanır və ya yenidən başladılır.

Fon proseslərinə nəzarət

  • İstifadə olunmayan xidmətlər söndürülür
  • Eyni anda bir antivirus işlədilir
  • Yeniləmələr iş saatlarından kənara salınır

Brauzer

  • Lazımsız əlavələr silinir, tab sayı azaldılır
  • Keş təmizlənir, hardware acceleration aktivdir

Zərərli proqramlar

Virus, miner və reklam proqramları CPU və şəbəkəni gizli yükləyir. Müntəzəm tam skan vacibdir.

07 · Yekun

Nəticə və tövsiyələr

Əsas nəticələr

  • Optimallaşdırma ölçmə ilə başlayır, darboğaz tapılır.
  • Ən böyük effekt: SSD, kifayət qədər RAM, yaxşı soyutma.
  • Startup və fon proseslər azaldılır.
  • Sistem yenilənir, təmizlənir, virusdan qorunur.
  • Nəticələr benchmark ilə təsdiqlənir.

Baxım planı

H

Həftəlik: zibil fayllar, brauzer keşi, yeniləmələr.

A

Aylıq: tam antivirus skanı, disk sağlamlığı, drayverlər.

İ

İllik: tozdan təmizləmə, termopasta, ehtiyat nüsxə.
